# Python Mastery: Assignments & Projects

Welcome to my Python learning repository! This project serves as a comprehensive archive of my journey through Python programming, covering everything from fundamental syntax to data structures, algorithms, and even gamified applications.

## 🚀 Overview

This repository is organized into several modules, each focusing on a specific area of Python development:

### 📁 Directory Structure

- **[DSA/](./DSA)**: A deep dive into Data Structures and Algorithms. Includes common problems like matrix operations, list manipulations, sorting, and dictionary usage.
- **[DL/](./DL)**: Includes various projects and logical scripts. Highlights include:
  - `TaskQuestApp`: A gamified task manager built with Tkinter.
- **[Numpy/](./Numpy)**: Exercises and implementations using the NumPy library for numerical computing.
- **[Assignments/](./)**: Multiple folders (`Assign-1`, `Assign 2`, `Assignment 3`) containing structured academic or practice problems.
- **[String Functions/](./string%20functions)**: Focused exercises on Python's built-in string manipulation capabilities.

## 🛠️ Key Topics Covered

- **Basics**: Variables, Loops (for/while), Conditionals.
- **Data Structures**: Lists (1D & 2D), Tuples, Dictionaries, Sets.
- **Logic & Algorithms**: Prime number checks, Fibonacci, Sorting, Reverse indexing.
- **GUI Development**: Desktop application building using `tkinter`.
- **Numerical Computing**: Array handling and matrix math with `NumPy`.

## 📈 Getting Started

To run any of the scripts, ensure you have Python installed. Many scripts are standalone `.py` files, while some use Jupyter Notebooks (`.ipynb`).

```bash
python path/to/script.py
```
